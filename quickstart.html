Quickstart

Scaffold a React app with @osdk/create-app, sign in to Foundry, and run your first OSDK query and action.

Foundry docsBootstrap a TypeScript app

Use @osdk/create-app to generate a React and Vite app that already signs users in, creates an OSDK client, and installs your generated SDK. By the end of this page you have a local app that lists Employee objects and applies the modifyEmployee action.

To add OSDK to an app you already have, see Installation instead.

Before you start

You need Node.js and an application in Foundry Developer Console. The CLI asks for these values, so collect them first:

ValueExampleWhere to find it in Developer Console
Foundry URLhttps://example.palantirfoundry.comThe URL of your Foundry stack.
Application RIDri.third-party-applications.main.application.1c66b352-…The application's Developer Console URL, /workspace/developer-console/app/<rid>.
OAuth client ID2650385ab6c5e0df3b44aff776b00a42OAuth & scopes.
Ontology RIDri.ontology.main.ontology.1df1ce4c-…Ontology SDK.
SDK package name@my-app/sdkThe npm install instructions of a generated SDK version. Must match @<scope>/sdk.
npm registry URLhttps://example.palantirfoundry.com/artifacts/api/repositories/<repository-rid>/contents/release/npmThe SDK's npm install instructions.

In Developer Console, also:

  1. Add the object types, link types, actions, and functions your app uses to the application's SDK, then generate a new version on SDK versions with the npm package type and the latest generator. Generate a new version whenever you change the resources.
  2. On OAuth & scopes, add http://localhost:8080/auth/callback as a redirect URL. The generated app runs on port 8080 and handles the sign-in redirect at that path.
  3. Get a Foundry token with access to the SDK's npm registry. The generated .npmrc reads it from the FOUNDRY_TOKEN environment variable when you install packages.

A 401 or 404 for @my-app/sdk means FOUNDRY_TOKEN is missing, expired, or lacks access to the registry.

Start the dev server

Open http://localhost:8080. The app sends you to Foundry to sign in, Foundry redirects back to /auth/callback, and the app returns you to the home page. If Foundry reports an invalid redirect URL, add http://localhost:8080/auth/callback on OAuth & scopes in Developer Console.

What is OSDK

The Ontology SDK gives TypeScript apps a typed client for your Foundry Ontology's objects, links, actions, functions, and interfaces.

Installation

Add @osdk/client, @osdk/oauth, @osdk/react, and your generated SDK to an existing app, with the npm registry setup and version rules they need.
